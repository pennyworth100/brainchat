# Private publication trigger authority

The October 12 local audit reproduced a journal-loss path in the private SQL
prototype: create a temporary `message_publication_pending` relation, place
`pg_temp` first in the caller search_path, then insert into `public.messages`.
The insert committed while the durable public journal received no row. The new
authority fixture failed its first retention assertion against the old SQL.
This prototype is not registered or deployed; this is not a production incident.

The trigger now binds its journal relation to TG_TABLE_SCHEMA using quoted
pg_catalog.format identifiers and parameterized values, pins the function
search_path to pg_catalog, pg_temp, and explicitly retains SECURITY INVOKER.
This preserves isolated non-public schemas. Installation still requires a
trusted migration search_path; this is not a generic migration installer.
No privileged definer or live role/grant changes are introduced.

The owned loopback fixture checks temp shadow resistance, function configuration,
and a NOLOGIN non-superuser writer: missing enqueue permission rejects the entire
message insert; explicit INSERT permission permits atomic journal retention.
The fixture role has neither journal UPDATE nor DELETE. All probe data, temp
objects and role/grants are enclosed in one rolled-back transaction.

This is not the complete deployed least-privilege policy: an invoker writer with
INSERT authority can also insert directly into the journal, and table ownership,
public-schema CREATE rights and superuser access need release-specific review.
The [restricted-login acceptance](3.0.33-publication-runtime-role.md) now proves
actual private issue/CAS/write/snapshot/claim/ACK with an append-only runtime role
and an explicit trusted-schema, temp-last subscriber search_path. Privileged
UPDATE/DELETE still lack a browser changefeed; deployed roles and pool settings,
backfill sizing, sustainable capacity and public activation remain open.
Actual HTTP producer journal acceptance is covered separately in
[the producer proof](3.0.33-public-producer-journal.md), not by this role test.
No public activation, migration registration or additional patch-version change
within the existing 3.0.33 draft.
