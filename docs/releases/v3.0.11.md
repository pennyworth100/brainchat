capacity until actual settlement after timeout/close; late errors cannot cause
late ACK, unhandled rejection or automatic retry.

# Private text-write outcome increment

`saveOnceWithOutcome`, preserving `saveOnce` compatibility. Independent-pool
same-key concurrency must produce one insertion and one existing receipt; a
successor resolving a lost COMMIT acknowledgment must report an existing receipt.

outbox, or network delivery guarantee. No public handlers or schema changed.
