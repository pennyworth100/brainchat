# Dimle 3.0.4

## Background conversation alerts

- Requests browser notification permission when a participant joins a room.
- Shows a native notification for new messages and attachments while the room is in the background.
- Tracks unread messages in the browser tab title and clears the count when the room becomes visible.
- Never alerts for the participant's own messages or replays existing room history.

## Reliable integrations

- Adds the authenticated `afterId` cursor to `GET /api/messages/:roomId` so live responders can fetch only unseen events.
- Keeps the timestamp-based `since` query available for backward compatibility.
- Covers notification decisions, unread titles, attachment summaries, cursor authorization, validation, and filtering in automated tests.
