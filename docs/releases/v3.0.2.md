# Dimle 3.0.2

Status: staging candidate. Production remains 3.0.1 until physical-iPhone QA,
security review and Max's explicit production acceptance are complete.

## Fixes

- Rejoin and refresh room state after transport reconnect and browser resume.
- Reconcile history/live events by persisted IDs without duplicates.
- Show truthful syncing/reconnecting state instead of a stale online count.
- Preserve unsent drafts when text or private delivery is unconfirmed.
- Refresh upload authentication and retry once after an explicit 401.
- Persist and broadcast accepted uploads independently of later socket loss.
- Return explicit upload errors while keeping chat usable.
- Preserve the v3.0.1 upload response contract without duplicate attachments.

## Verification gates

- 11 unit/regression tests.
- TypeScript validation and production build.
- CI-backed HTTP, Socket.IO and PostgreSQL integration regression.
- Mobile WebKit/iPhone 13 emulation.
- Physical-iPhone reconnect and original-PDF check (required before production).
- Independent security review and Max's production acceptance (required).
